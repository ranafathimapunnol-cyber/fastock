# AI Usage Policy

## Project
Fastock – AI-Powered Inventory Management Copilot

## AI Tools
- Google Gemini: LLM provider.
- LangChain: LLM integration.
- LangGraph: Agent orchestration.
- GitHub Copilot / ChatGPT: Development assistance.

## Usage Guidelines
- AI-generated code must be reviewed and tested.
- Never share API keys, passwords or private credentials.
- Use synthetic data only.
- Document significant AI-assisted implementation.
- Never allow AI to execute business actions without human approval.

## Human Responsibility
The developer is responsible for architecture, code quality, security,
testing, debugging and final implementation decisions.
