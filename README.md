# Fastock

**Smart Stock. Smarter Decisions.**

Fastock is an AI-powered inventory management platform with an intelligent
copilot for stock risk analysis, purchase order recommendations and
stock discrepancy investigation.

## Main Features
- Inventory and stock movement management
- AI-powered stock risk analysis
- RAG-based inventory knowledge retrieval
- Purchase order proposals with human approval
- Stock discrepancy investigation
- Audit logs and agent run monitoring

## Technology Stack
- Next.js, React, TypeScript, Tailwind CSS
- FastAPI, Python, Pydantic, SQLAlchemy
- PostgreSQL, pgvector, MongoDB, Redis
- Gemini, LangChain, LangGraph
- Flask Action Executor
- Docker, Nginx, AWS

## Project Status
Approved capstone project – Development in progress.
